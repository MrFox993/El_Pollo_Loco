# El Pollo Loco

**El Pollo Loco** is a browser-based, 2D side-scrolling platform game, inspired by classic jump-and-run adventures. Built with HTML, CSS, and JavaScript, it features original characters, multiple levels, and engaging gameplay mechanics.

---

## Features

- **Multiple Levels:** Progress through distinct levels, each with unique obstacles and enemies.
- **Playable on Desktop & Mobile:** Responsive controls for both keyboard and mobile devices.
- **Game States:** Start, pause, resume, and navigate between levels and menus.
- **Audio Effects:** Immersive background music and sound effects, including mute support.
- **Collectables:** Collect coins and bottles, throw objects, and interact with the game world.
- **Boss Fights & Enemies:** Face off against chickens and "endboss" enemies.
- **UI Screens:** Main menu, controls guide, legal notice, win/loss overlays, and mobile-friendly gamepad.

---

## Controls

**Desktop:**
- Move Left: `Left Arrow` or `A`
- Move Right: `Right Arrow` or `D`
- Jump: `Up Arrow` or `W` or `Spacebar`
- Throw Bottle: `C`
- Pause Game: `P`
- Mute/Unmute: `M`

**Mobile:**
- On-screen buttons for movement, jump, throw, pause, and mute.

---

## Project Structure

- `index.html` — Main HTML file and entry point.
- `assets/` — All game assets (images, sounds, icons, fonts).
- `classes/` — JavaScript classes for game objects (Character, Enemy, Level, World, etc.).
- `levels/` — Level definitions.
- `scripts/` — Core game logic and UI scripts.
- `styles/` — Game styling.

---

## Getting Started

Simply open `index.html` in your web browser. No installation required!
